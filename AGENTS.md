# O Grimório do Editor

- Trabalhar nesta pasta. Preservar referências e arquivos originais.
- Fonte factual: `references/Portfolio Layout  (1).pdf`; composição: `references/Portfólio do Grimório do Editor.png`.
- React + Vite + TypeScript, CSS com tokens, SVG e HTML5 Video. GSAP pontual; respeitar reduced-motion.
- Conteúdo editável em `src/data/content.ts`. Não inventar clientes, depoimentos, números, resultados ou vídeos reais.
- Capitulares são a primeira letra real do título. Nunca repetir essa letra nem usar números romanos decorativos.
- Mobile-first: validar 390, 768 e 1440px; vídeo antes do texto; sete habilidades; feedbacks antes do epílogo.
- Consultar `docs/ART_DIRECTION.md`; workflows locais em `skills/`.
- Executar build e, quando possível, `npm run qa`. Registrar limitações reais em `docs/QA.md`.
